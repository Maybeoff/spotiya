# Установка штатными средствами колонки

Быстрая команда в начале основного README устанавливает и обновляет Spotiya.
При наличии `/data/opt/spotify-connect/spotiya` она сразу вызывает его `--update`,
без загрузки установщика. Если приёмник отсутствует, штатный `maind` получает
`install.sh` из `main` на GitHub. Сам скрипт также поддерживает оба сценария.

`../install.sh` загружает последний стабильный пакет и `SHA256SUMS` непосредственно
из GitHub Releases. VPS и дополнительный HTTPS-загрузчик не используются.
Обновление следует опубликованным стабильным релизам; версия из `main` становится
доступна для этого обновления после публикации нового релиза.

На Мини 2 штатный BusyBox wget не поддерживает HTTPS. В прошивке есть другой
клиент: `maind --gst-launch` с `souphttpsrc` и `filesink`. Для него необходимо
явно указать `ssl-ca-file=/etc/ssl/certs/ca-certificates.crt` и оставить
`ssl-strict=true`. Без явного CA-файла проверенная прошивка не загружает HTTPS;
отключение проверки сертификатов не используется. Проверены GitHub raw,
редиректы Releases и полный архив; самоподписанный сертификат отклоняется.

`maind` возвращает код 0 даже после некоторых ошибок GStreamer. Поэтому скрипт
проверяет сообщение `EOS: end of stream`, отсутствие `ERROR from` и непустой
результат. Частичный файл не передаётся установщику. Затем проверяется SHA-256
архива: принимается только одна корректная запись с точным именем пакета.
Если между двумя загрузками вышел новый релиз, несовпадение хеша остановит
установку; команду можно повторить.

Архив распаковывается через `gzip -dc` и `tar -xf`: у штатного tar нет `-z`.
Проверяется little-endian ARM32 userspace; имя ядра `aarch64` допустимо.
Установку, автозапуск, сохранение состояния и откат выполняет установщик из
проверенного пакета. Уже установленная Spotiya обновляется своим `--update`.

`--check` скачивает пакет, проверяет хеш и запускаемость бинарника. Она не
вызывает установку, обновление, остановку или запуск службы. Временные файлы
удаляются. Воспроизведение и дополнения скрипт не запускает.

Этот способ проверен на Мини 2; наличие `--gst-launch` и нужных элементов на
других прошивках ещё не проверено. Если их нет, используйте установку через ПК.
Actions готовит `install.sh` и `INSTALL_SHA256SUMS` как отдельные файлы релиза.
